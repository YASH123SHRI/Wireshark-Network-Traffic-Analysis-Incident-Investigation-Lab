# Exporting Objects from Network Traffic

## Objective

Use Wireshark's Export Objects feature to identify and extract files transferred through supported network protocols.

---

## Background

Network traffic can contain files and other application-layer objects transferred between systems.

Wireshark provides an **Export Objects** feature that allows analysts to extract supported objects from packet captures for further examination.

---

## Lab Environment

| Component | Details |
|---|---|
| Operating System | Windows 11 |
| Packet Analyzer | Wireshark |
| Capture Format | PCAPNG |
