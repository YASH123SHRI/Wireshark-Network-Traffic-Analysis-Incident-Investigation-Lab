# Follow TCP Stream

## Objective

Use Wireshark's Follow TCP Stream feature to reconstruct and analyze the application-layer communication between two endpoints.

---

## Background

A TCP stream consists of packets exchanged between a client and server during a TCP session.

Wireshark's **Follow TCP Stream** feature reconstructs the data exchanged within a selected TCP connection, making it easier to understand the complete conversation instead of analyzing individual packets.

---

## Lab Environment

| Component | Details |
|---|---|
| Operating System | Windows 11 |
| Packet Analyzer | Wireshark |
| Capture Format | PCAPNG |
